Helm

Helm is mission control for a fleet of autonomous coding agents. It runs entirely on your own machine, supervises many projects at once, and holds every irreversible action — every push, deploy, publish, install or file write — behind an approval you personally give.

This workbook walks every flow in the product end to end. Work top to bottom; each test says what to do, what should happen, and why it matters. Mark each one as you go — your marks are saved in this browser, and Export results hands you a copy to send on.
